What This Is
Ask your data a question, get a straight answer

Conversational Analytics lets any stakeholder query data in plain English and get instant, SQL backed answers. No dashboard building, no waiting on an analyst, no SQL knowledge required. This site has two working examples of it: a Christmas mood tracker built on Claude and web research, and an ecommerce agent built on BigQuery Conversational Analytics.

Why It Benefits Users
  • Stakeholders self-serve instead of queuing for an analyst
  • Answers come with the logic behind them, not just a number
  • Follow up questions build on the last one, no re-explaining context
  • Faster read on sentiment and performance, closer to real time thinking
How It Works
01
AskPlain English question, the way you'd ask a colleague.
02
InterpretAgent applies configured instructions and glossary so it knows what your data means.
03
GenerateModel writes the query against your connected data, shown transparently.
04
ExecuteQuery runs inside your own environment, with limits to prevent runaway cost.
05
FormatAnswer comes back as text, a table, or a chart depending on the question.
06
ContinueSession keeps context, so a follow up question just works without repeating background.
Two different backends here on purpose. Trendspotter runs on Claude plus web research through a small proxy. The ecommerce agent runs on Google BigQuery Conversational Analytics through the ca-proxy Cloud Run service. See README.md in this repo for the exact keys each one needs.

Limitations, when not to use this
  • Complex multi step statistical modelling, use a data scientist instead
  • Anything needing real time data, this dataset lags 24 hours
  • Recurring reporting a stakeholder checks daily, build a dashboard instead
  • Queries likely to exceed the 3 MB result cap or 8,192 token limit
