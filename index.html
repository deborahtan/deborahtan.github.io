What This Is
Ask your data a question, get a straight answer

Conversational Analytics lets any stakeholder query data in plain English and get answers. This saves time spent on ad hoc Q&A. This site has two working examples: a Christmas mood tracker built on the Trends MCP, and an analytics agent built on BigQuery Conversational Analytics API.

Why It Benefits Users
  • Stakeholders self-serve instead of queuing for an analyst
  • People can ask followup questions and not have to re-explain context
  • Faster time to insight as the data synthesises many sources
How It Works

04

05

06
ContinueSession keeps context, so a follow up question just works without repeating background.

Limitations, when not to use this
  • Complex and multilayered questions, this is better off with dedicated analysis
  • Anything needing real-time data as this updates daily
  • Recurring reporting a stakeholder checks daily, build a static report/dashboard instead
  • Queries likely to exceed the 3 MB result cap or 8,192 token limit
